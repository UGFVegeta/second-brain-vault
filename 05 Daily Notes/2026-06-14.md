## Erkenntnisse
- WordPress/Betheme erlaubt via `Zusätzliches CSS` weitreichende visuelle Änderungen ohne Theme-Anpassung – Sidebar lässt sich mit CSS ausblenden (`#sidebar { display: none }`).
- Logo-Einbettung als Base64 in HTML: iCloud-Dateien können nicht direkt per Bash gelesen werden (Resource deadlock) → erst mit Read-Tool herunterladen, dann per `base64`-CLI kodieren.
- Betheme nutzt `<a> > <span>` Struktur für Nav-Links → CSS muss beide Ebenen targeten.
- BeBuilder Custom Classes (`data-css-class`) sind der eleganteste Weg um einzelne Sektionen dunkel zu machen, ohne das gesamte Theme zu ändern.
