## Erkenntnisse
- ExcalidrawAutomate API (`connectObjects`) ist der einzig zuverlässige Weg für verbundene Pfeile in Obsidian – manuelles JSON-Binding funktioniert nicht stabil
- Brave Search API hat kein echtes Gratis-Tier mehr – Kreditkarte erforderlich → Tavily ist die bessere kostenlose Alternative für KI-Recherche
- Perplexity PayPal-Jahresabo = nur Web-Zugang, kein API-Zugriff → API wäre separat kostenpflichtig
- Apple Notes: Claude hat per AppleScript vollen Zugriff (833 Notizen, 19 Ordner) – wird nur auf Anfrage genutzt
- kepano/obsidian-skills ist kein Obsidian-Plugin, sondern Wissens-Dateien die Claude beibringen wie er korrekt mit Obsidian-Syntax umgeht
- GarethManning/education-agent-skills: echtes, evidenzbasiertes Repo (288 Stars, Stand Juni 2026) – für Realschullehrer sind ~15 von 165 Skills relevant; kein deutscher Schulkontext vorhanden
- Firecrawl: 1.025 Credits verfügbar → Web-Recherche direkt aus Claude Code möglich
- NotebookLM: Podcasts und Study Guides aus Vault-Inhalten generierbar
- Ameisen an der Terrassentür: Essig (Duftspuren), Zimt (Barriere), Backpulver+Zucker (Köder), langfristig Silikon abdichten
- Cookidoo: Login nötig für Rezeptzugriff – Firecrawl-Ansatz (einmaliger Login pro Session) machbar; Wunsch: Claude schlägt wöchentlich 4 Rezepte vor, extrahiert Zutaten
- Kalender: Google Calendar MCP verbunden, aber Oskar nutzt primär Apple Kalender → Claude Code hat hier keinen vollständigen Zugriff; Claude iOS App hat Vorteil für Kalender unterwegs
- Obsidian Sync recherchiert: Bewertung B+, zuverlässig, E2E-verschlüsselt (AES-256), unabhängige Sicherheitsaudits; Kritik: US-Server (AWS), closed source, teuer pro GB (1 GB für 4$/Monat)
- Eigener Server (GoGreen): datenschutzrechtlich beste Option – DE-Server, DSGVO-konform, Ökostrom, via Nextcloud + "Remotely Save" Plugin oder Obsidian LiveSync
- Synology NAS für reinen Vault-Sync nicht sinnvoll (überdimensioniert, ~540€ Einmalkosten); da iCloud bereits vorhanden → iCloud mit erweitertem Datenschutz ist die pragmatischste Lösung
- Synology DS225+ ist aktueller Nachfolger der DS224+ (seit Computex 2025): gleiches Innenleben, aber 2,5-Gbps-LAN statt 1 Gbps
- Erweiterter Datenschutz (iCloud): per Apple-ID-Einstellung, betrifft nur eigenen Account – Frau im Familienabo nicht betroffen; Voraussetzung: Wiederherstellungsschlüssel oder -kontakt einrichten
