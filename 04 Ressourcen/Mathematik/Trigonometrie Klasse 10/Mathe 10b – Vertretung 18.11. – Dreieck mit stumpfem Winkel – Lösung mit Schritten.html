Aufgabe 1S. 16 Nr. 3 c rechts, gemeinsam: so steht es am Ende an der Tafel

① Höhe einzeichnen
c über A hinaus verlängern,
Lot von C: Fußpunkt F, Strecke FA = x
Das Dreieck FBC ist rechtwinklig, das Dreieck FAC auch.
② α':
α' = 180° − 115°
α' = 65,0°
Nebenwinkel von α im kleinen Dreieck FAC.
③ hc:
sin 65,0° = hc4,4 | · 4,4
hc = 4,4 · sin 65,0°
hc = 3,99 cm
Im Dreieck FAC: hc ist Gegenkathete, 4,4 cm die Hypotenuse.
④ x:
cos 65,0° = x4,4 | · 4,4
x = 4,4 · cos 65,0°
x = 1,86 cm
Im Dreieck FAC: x ist Ankathete.
⑤ x + c:
x + c = √8,4² − 3,99²
x + c = 7,39 cm
Pythagoras im großen Dreieck FBC: 8,4 cm ist die Hypotenuse.
⑥ c:
c = 7,39 − 1,86
c = 5,53 cm
x wieder abziehen.
⑦ β:
sin β = 3,998,4
sin β = 0,4750
β = 28,4°
Im großen Dreieck FBC: hc liegt β gegenüber. Taste sin⁻¹.
⑧ Probe (wer mag):
γ = 180° − 115° − 28,4°
γ = 36,6°
Winkelsumme. γ wird hier nicht verlangt.
Ergebnis: c = 5,53 cm ≈ 5,5 cm; β = 28,4°
So vorgehen: erst die Skizze groß an die Tafel, dann fragen: „Wo liegt die Höhe von C aus?“ Die Klasse merkt, dass sie die Seite c nicht trifft. Dann c verlängern und hc einzeichnen lassen. Jeden Schritt kurz selbst rechnen lassen (1 bis 2 Minuten), dann vergleichen und an die Tafel. Merksatz für die Klasse: Erst die Höhe, dann die rechtwinkligen Dreiecke suchen, dann sin, cos oder Pythagoras.
Typische Fehler: Taschenrechner auf RAD statt DEG. Mit 115° statt 65° gerechnet. Bei ⑤ 8,4² + hc² statt minus. Bei ⑥ x vergessen abzuziehen. Die Buchlösung hat x = 1,85 und c + x = 7,38 (anders gerundet), c = 5,53 cm stimmt.
