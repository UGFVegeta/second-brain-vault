Dreieck: Ecken abreißen (ausgefüllt)

Aufgabe:
  1. Auf Schmierpapier ein großes Dreieck zeichnen, die Winkel bunt markieren.
  2. Das Dreieck ausschneiden.
  3. Die drei Ecken abreißen.
  4. Die Ecken an einem Punkt zusammenlegen.

Die drei Ecken ergeben einen gestreckten Winkel: 180°.

Merkheft: Winkelsumme im Dreieck

In jedem Dreieck gilt: α + β + γ = 180°
Warum?
1Parallele p zu AB durch C.
2Wechselwinkel: α′ = α, β′ = β
3Bei C: α′ + γ + β′ = 180° (gestreckt)
Fehlenden Winkel berechnen
1Gesucht: γ
265° + 45° = 110°
3γ = 180° − 110° = 70°
4Probe: Summe 180°

Fehlender Winkel im Dreieck

  1. Was fehlt?
  2. Die zwei bekannten Winkel addieren.
  3. Von 180° abziehen.
  4. Probe: Alle drei ergeben 180°.
Weitere Beispiele
α = 90°, β = 35°: γ = 55°
α = 120°, γ = 25°: β = 35°
β = 48°, γ = 62°: α = 70°
α = 20°, β = 20°: γ = 140°
α = 60°, β = 60°: γ = 60°
α = 38,5°, β = 41,5°: γ = 100°
