Aufgabe 18★★★
Aufgabe: Lies die Schnittpunkte von Gerade g und Parabel p ab. Bestimme außerdem die Nullstellen der Parabel.
  • Schnittpunkte: (0 | −3) und (3 | 0)
  • Nullstellen von p: x = −1 und x = 3
p: y = x² − 2x − 3,   g: y = x − 3.
Schnitt: x² − 2x − 3 = x − 3 → x² − 3x = 0 → x(x − 3) = 0 → x = 0; x = 3.
Nullstellen: x² − 2x − 3 = (x − 3)(x + 1) = 0.
