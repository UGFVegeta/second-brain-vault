# Anatomy Trains – Thomas Myers

## Warum dieses Buch?

Der Körper funktioniert nicht aus isolierten Einzelmuskeln – er zieht und schiebt durch **verbundene Faszien-Linien** (Anatomy Trains). Wer das versteht, begreift warum eine Hamstring-Verletzung oft woanders beginnt, warum ein straffer Wadenmuskel auf die Kniescheibe drückt, und wie Schwimmen, Radfahren und Laufen als System zusammenwirken.

Besonders relevant: [[03 Bereiche/Triathlon/Hamstring Reha – Proximale Tendinopathie]]

---

## Die 7 Anatomy Trains (Faszien-Linien)

### 1. Superficial Back Line (SBL) – Hintere Oberflächen-Linie
```
Fußsohle → Plantarfaszie → Wade → Hamstrings → Kreuzbein →
Rückenstrecker → Nacken → Schädeldach (Stirn)
```
**Relevant für:** Hamstring-Verletzungen, Rückenschmerzen, Plantarfasziitis
> ⚠️ Oskars proximale Hamstring-Tendinopathie sitzt mitten in dieser Linie. Tightness in Wade oder Fußsohle kann die Hamstrings unter Dauerspannung setzen.

---

### 2. Superficial Front Line (SFL) – Vordere Oberflächen-Linie
```
Zehen → Schienbein → Quadrizeps → Bauchmuskeln → Brustkorb → Hals
```
**Relevant für:** Knieschmerzen, Hüftbeuger-Probleme, Rundrücken beim Laufen

---

### 3. Lateral Line (LL) – Seitliche Linie
```
Außenseite Fuß → IT-Band → TFL → seitliche Rumpfmuskeln → Neck
```
**Relevant für:** IT-Band-Syndrom (läuferklassiker), Knie-Außenschmerzen

---

### 4. Spiral Line (SPL) – Spirallinie
```
Wickelt sich um den gesamten Körper – verbindet gegenüberliegende Körperhälften
```
**Relevant für:** Rotationsbewegungen, Laufstil-Asymmetrien

---

### 5. Deep Front Line (DFL) – Tiefe Frontlinie
```
Fußgewölbe → tiefe Wade → Hüftbeuger (Psoas) → Zwerchfell → Zunge
```
**Relevant für:** Kernstabilität, Atemtechnik, chronische Hüftprobleme

---

### 6. Arm Lines (4)
Verbinden Finger über Arm und Schulter mit dem Rumpf.
**Relevant für:** Schwimmschulter, Zugkraft beim Kraulen

---

### 7. Functional Lines
Verbinden Arm mit gegenüberliegendem Bein – z.B. linker Arm ↔ rechtes Bein.
**Relevant für:** Laufbewegung, Rotationsstabilität

---

## Key-Takeaways

> [!tip] Das wichtigste Konzept
> **Schmerz ist nicht immer dort, wo das Problem ist.**
> Die SBL verbindet Fußsohle mit Hamstrings mit Rücken – ein Problem in Calw oder Frankfurt kann in Weinstadt wehtun.

- **Faszien** sind das Bindegewebe das alles umhüllt und verbindet – kein passives Füllmaterial, sondern aktives Kraftübertragungssystem
- **Verspannung zieht die gesamte Linie unter Spannung** → Behandle nie nur den Schmerzpunkt
- **Für Triathleten:** Schwimmen (Arm Lines), Radfahren (DFL, SFL), Laufen (SBL, LL) involvieren verschiedene Linien → Übergangs-Müdigkeit hat fasziale Ursachen
- **Selbstanwendung:** Foam Rolling entlang einer Linie (nicht nur an der Schmerzstelle) kann effektiver sein als gezieltes Punkt-Rollen

## Verbindung zu Oskars Hamstring-Verletzung

Die proximale Hamstring-Tendinopathie rechts sitzt in der **Superficial Back Line**:

```
Fußsohle → Plantarfaszie → Achillessehne → Wade (Gastrocnemius)
→ Hamstrings ← DU BIST HIER
→ Sakrotuberosal-Band → Erector spinae → ...
```

**Mögliche Ursachen die über die Linie kommen:**
- Straffe Wade (Calves) → zieht an Hamstrings
- Schwacher Glute max → Hamstring übernimmt kompensatorisch
- Becken-Kippung beim Laufen → chronische Zuglast

→ Beim Physio ansprechen: Gesamte SBL auf Spannung prüfen, nicht nur Hamstring
