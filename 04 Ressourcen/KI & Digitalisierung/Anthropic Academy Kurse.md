# Anthropic Academy Kurse

Kostenlose Kurse von Anthropic, mit Zertifikat, gehostet auf Skilljar (eigener Login nötig). Alle Kurse auf Englisch.

- Kurskatalog: https://anthropic.skilljar.com/
- Rahmenseite: https://www.anthropic.com/learn

Stand 23.07.2026: 20 Kurse plus ein Lernpfad.

## Stufe 1 – Fundament

- [ ] [AI Fluency: Framework & Foundations](https://anthropic.skilljar.com/ai-fluency-framework-foundations) – Grundgerüst, auf dem alle weiteren AI-Fluency-Kurse aufbauen
- [ ] [AI Capabilities and Limitations](https://anthropic.skilljar.com/ai-capabilities-and-limitations) – wie KI funktioniert, gute Argumentationsbasis fürs Kollegium
- [ ] [Claude 101](https://anthropic.skilljar.com/claude-101) – querlesen reicht wahrscheinlich

## Stufe 2 – Schule (Kernnutzen)

- [ ] [AI Fluency for educators](https://anthropic.skilljar.com/ai-fluency-for-educators) – Übertragung auf Unterricht und Schulstrategie, anschlussfähig an die Konrektor-Bewerbung
- [ ] [AI Fluency for pK-12 Educators](https://anthropic.skilljar.com/path/ai-fluency-for-pk-12-educators) – Lernpfad aus 2 Kursen, näher an Schule als an Hochschule
- [ ] [Teaching AI Fluency](https://anthropic.skilljar.com/teaching-ai-fluency) – Vermittlung in Fortbildungen, Basis für eigene Fortbildungsangebote
- [ ] [AI Fluency for students](https://anthropic.skilljar.com/ai-fluency-for-students) – Schülerperspektive, hilfreich für Regeln und Aufgabenformate

## Stufe 3 – Werkzeug schärfen (Claude Code)

- [ ] [Claude Code 101](https://anthropic.skilljar.com/claude-code-101)
- [ ] [Introduction to agent skills](https://anthropic.skilljar.com/introduction-to-agent-skills) – direkt relevant für die eigenen Vault-Skills
- [ ] [Introduction to subagents](https://anthropic.skilljar.com/introduction-to-subagents)
- [ ] [Claude Code in Action](https://anthropic.skilljar.com/claude-code-in-action) – großer Deep Dive, mehrere Stunden
- [ ] [Introduction to Claude Cowork](https://anthropic.skilljar.com/introduction-to-claude-cowork)

## Stufe 4 – optional, Entwicklerschiene

- [ ] [Claude Platform 101](https://anthropic.skilljar.com/claude-platform-101)
- [ ] [Building with the Claude API](https://anthropic.skilljar.com/claude-with-the-anthropic-api)
- [ ] [Introduction to Model Context Protocol](https://anthropic.skilljar.com/introduction-to-model-context-protocol)
- [ ] [Model Context Protocol: Advanced Topics](https://anthropic.skilljar.com/model-context-protocol-advanced-topics)

## Nicht relevant

Claude with Amazon Bedrock, Claude on Google Cloud, AI Fluency for nonprofits, AI Fluency for Small Businesses, AI Fluency for Builders. Andere Zielgruppen und Kontexte.

## Priorität

Größter Hebel für die Konrektor-Bewerbung: AI Fluency Framework & Foundations, AI Fluency for educators, Teaching AI Fluency.
Größter Hebel für die tägliche Arbeit im Vault: Introduction to agent skills, Claude Code in Action.
