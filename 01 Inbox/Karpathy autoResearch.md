# Karpathy autoResearch

Auf YouTube empfohlen bekommen, tiefer einsteigen geplant.

## Was es ist

Open-Source-Projekt von Andrej Karpathy (ehem. OpenAI-Gründer, Tesla AI-Chef).

**Kernidee:** Ein KI-Agent läuft autonom in einer Schleife und verbessert sich selbst beim Trainieren von ML-Modellen – ohne menschliches Eingreifen.

## Wie es funktioniert

1. Agent **modifiziert** selbst den PyTorch-Trainingscode
2. **Trainiert** ein Modell (~5 Min. pro Experiment)
3. **Evaluiert** das Ergebnis
4. **Behält** Verbesserungen, **verwirft** Rückschritte
5. **Wiederholt** – stundenlang / über Nacht

## Warum relevant

- Früher konkreter Schritt Richtung **autonome KI-Forschung**
- Selbes Prinzip wie in Claude Code / agentic AI: autonom iterieren statt menschliche Schritt-für-Schritt-Kontrolle
- Karpathy ist einer der besten KI-Erklärer – Video lohnt sich
